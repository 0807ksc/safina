# project-context-v3.md

## 프로젝트명
Safina

브랜드 의미:
Safina는 Safe에서 파생된 조어로,
“안전하고 부드러운 한입”을 상징하는 글로벌 가족 식품 안전 브랜드.

발음: 세피나
특징: 영어권/비영어권 모두 발음이 쉽고, 특정 언어 충돌 가능성이 낮음.
포지셔닝: 의료앱이 아닌 가족 중심 식품 안전 & 성장 관리 플랫폼.

---

# 1. 제품 정의

Safina는 부모가 자녀의 알러지 및 식이 제한을 설정하고,
자녀는 음식이나 급식을 카메라로 비추기만 해도
실시간으로 위험 여부를 확인할 수 있는
가족 중심 실시간 식품 안전 플랫폼이다.

핵심 구조:
- 실시간 카메라 분석
- 부모-자녀 관계 기반 알림 시스템
- 알러지 + 영양 분석 확장 가능 구조

---

# 2. 핵심 UX 구조 (Zero-Wait RealTime)

## 자녀 모드

1. 앱 실행 즉시 카메라 ON
2. 촬영 버튼 없음 (실시간 분석)
3. 화면 하단 대형 상태 표시등

색상 체계:
- 회색: 분석 중
- 초록: 안전
- 노랑: 확인 필요
- 빨강: 위험

4. 결과 확정 시:
- 진동 알림
- 색상 전환
- 자동 상세 화면 이동

5. 불확실할 경우:
- 1~2개 질문 카드 노출
  예: "견과류 들어가나요?"
      "크림치즈 사용했나요?"

UX 원칙:
- 초등학생 기준
- 텍스트 최소화
- 색상 중심 인지
- 3초 내 판단 가능

---

# 3. 부모-자녀 관계 구조

## 보호자 기능
- 자녀 프로필 다중 생성
- 알러지 항목 및 심각도 설정
- 식이 제한 설정 (채식, 할랄 등)
- 스캔 기록 열람
- 위험 발생 시 푸시 알림 수신

## 자녀 기능
- 실시간 음식 확인
- 결과 확인
- 질문 확인
- 기록 자동 저장

## 알림 정책
- 빨강: 무조건 부모 알림
- 노랑: 설정에 따라 알림 여부 결정

---

# 4. 분석 구조 개념

1. 실시간 영상 프레임 분석
2. 음식 객체 인식
3. OCR 텍스트 추출
4. 사용자 입력 병합 (선택)
5. 룰엔진 매칭
   - 직접 성분 탐지
   - 중간 재료 역추론
6. 신뢰도 계산
7. 최종 색상 결정

불확실한 경우 항상 "주의(노랑)" 처리

---

# 5. 영양 분석 확장 기능

촬영 기반 추가 서비스:

- 칼로리 추정
- 탄수/단백질/지방 비율
- 당류 과다 여부
- 나트륨 위험도
- 일일 권장량 대비 비율
- 주간 영양 리포트
- 편식 패턴 분석
- 가공식품 빈도 분석
- 성장기 영양 부족 경고

부모 대시보드 예:
오늘 섭취
- 칼로리 78%
- 당류 120%
- 단백질 부족

---

# 6. 학교 급식 확장

가능 기능:

- 학교 급식 자동 영양 분석
- 영양 점수화
- 채소 비율 점수
- 튀김 지수
- 학생 만족도 집계
- 학교별 건강 급식 비교

확장 방향:
- 교육청 협업
- 지역별 통계 리포트
- 공공 데이터 기반 개선 제안

주의:
- 학교 비난 구조 금지
- 객관적 지표 기반 평가

---

# 7. 회사 활용 데이터 (익명화 전제)
